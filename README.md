Guynacci Bonhomme  
CAI5735 Applied Data Science in Health

## Research question
How does the number of medications relate to hospital stay length,
and does this relationship differ by readmission status?

## Files
- diabetes_midterm.py: marimo notebook with the code and explanations.
- diabetes_130.csv: course dataset used for the analysis.

## How to run
Import diabetes_midterm.py into molab, upload diabetes_130.csv
through the Files sidebar, and run all cells.

## Main finding
Longer hospital stays generally had more medications.
This pattern was similar across the three readmission groups.
These results show an association, not cause and effect.
